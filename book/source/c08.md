# Python desde cero: de una carpeta a tu primera gráfica

- Distinguir terminal, intérprete, archivo y cuaderno antes de ejecutar instrucciones.
- Crear un entorno virtual y escribir funciones que operen sobre arrays.
- Generar una gráfica y guardar resultados usando rutas portables.

### Cuatro cosas que al principio se parecen

La terminal es la ventana donde das órdenes al sistema: abrir carpetas o ejecutar programas. Python es un programa que interpreta código. Un archivo terminado en .py contiene instrucciones que Python ejecuta de arriba abajo. Un cuaderno de Jupyter mezcla texto, código y resultados en celdas; conserva variables en memoria entre ejecuciones.

Una línea como «python modelo.py» pertenece a la terminal. Una línea como «import numpy as np» pertenece a Python. Si ves el indicador >>>, estás dentro del intérprete interactivo: no escribas allí comandos del sistema.

En un cuaderno puedes ejecutar la celda inferior antes que la superior y conservar un estado que ya no coincide con el texto visible. Antes de compartirlo, reinicia el núcleo y ejecuta todas las celdas en orden. Un resultado reproducible debe poder recuperarse desde un inicio limpio.

### Preparar una carpeta y su entorno

Instala Python 3 desde su distribución oficial, eligiendo una versión estable compatible con las bibliotecas que vas a usar [R01]. Abre una carpeta de proyecto, por ejemplo «curso_circuitos». Todos los comandos siguientes se ejecutan desde esa carpeta.

Un entorno virtual contiene el intérprete y los paquetes asociados al proyecto; ayuda a evitar que bibliotecas de trabajos distintos interfieran. La documentación explica que puede usarse invocando directamente su intérprete, sin activarlo [R02].

En Windows, desde PowerShell:

~~~powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install numpy scipy matplotlib
.\.venv\Scripts\python.exe --version
~~~

Si el comando «py» no existe pero «python --version» identifica tu instalación de Python 3, usa «python -m venv .venv». En Linux o macOS:

~~~bash
python3 -m venv .venv
.venv/bin/python -m pip install numpy scipy matplotlib
.venv/bin/python --version
~~~

Conserva tu código fuera de .venv. Para cambiar de ordenador, recrea el entorno; no copies esa carpeta como si fuera un documento. Cuando el proyecto funcione, registra versiones con «python -m pip freeze» usando el intérprete del entorno. Es una instantánea de paquetes, no una garantía absoluta de compatibilidad entre plataformas.

JupyterLab es opcional. Su instalación y lanzamiento están documentados por el proyecto [R11]. Puedes instalarlo con el mismo intérprete mediante «-m pip install jupyterlab» y abrirlo mediante «-m jupyterlab». Para seguir este libro también basta un editor de texto y archivos .py.

### Variables: poner nombre a una cantidad

En Python el signo igual asigna un valor a un nombre. «x = 2» guarda un valor; «x == 2» pregunta si dos valores son iguales. Los decimales se escriben con punto, aunque el libro use coma en el texto. La multiplicación necesita asterisco y la potencia se escribe con dos asteriscos.

Una lista agrupa elementos. Sus posiciones empiezan en cero. Una función agrupa instrucciones y devuelve un resultado con return. La indentación forma parte del lenguaje [R09]:

~~~python
tiempos = [0.0, 1.0, 2.0]
valor_inicial = 8.0

def aproximacion_lineal(x, perdida, paso):
    cambio = -perdida * x
    return x + paso * cambio

nuevo = aproximacion_lineal(valor_inicial, 0.5, 0.1)
print(tiempos[0], nuevo)
~~~

El resultado es 0.0 y 7.6. Primero calculaste una velocidad de pérdida de −4 unidades por tiempo. Durante un paso de 0,1, aproximaste una pérdida de 0,4. El nombre «cambio» en la función representa una velocidad, no una cantidad perdida; escribir unidades en comentarios evita confundirlas.

Una función no cambia una variable exterior solo porque sus argumentos tengan nombres parecidos. El valor devuelto debe asignarse o utilizarse. Y un error de nombre suele significar que olvidaste definirlo o ejecutaste las instrucciones en otro orden.

### Arrays: trabajar con una columna entera

NumPy ofrece arrays numéricos, formas y operaciones sobre muchos valores [R03]. Una lista y un array pueden parecerse al imprimirlos, pero no hacen lo mismo. «[1, 2] * 2» repite la lista; «np.array([1, 2]) * 2» multiplica cada entrada.

Este programa completo calcula una pérdida exponencial ilustrativa, sin datos experimentales:

~~~python
from pathlib import Path
import numpy as np
import matplotlib.pyplot as plt

x0 = 8.0
delta = 0.5
t = np.linspace(0.0, 6.0, 121)
x = x0 * np.exp(-delta * t)

salida = Path("salidas")
salida.mkdir(exist_ok=True)

fig, ax = plt.subplots(figsize=(6, 4))
ax.plot(t, x, color="#2166ac", linewidth=2)
ax.set_xlabel("Tiempo (h)")
ax.set_ylabel("Concentración (u. arbitrarias)")
ax.set_title("Modelo ilustrativo: pérdida de primer orden")
fig.tight_layout()
fig.savefig(salida / "perdida.png", dpi=200)
plt.show()

np.savetxt(
    salida / "perdida.csv",
    np.column_stack((t, x)),
    delimiter=",",
    header="tiempo_h,concentracion",
    comments=""
)
~~~

La forma de t es (121,): una dimensión con 121 valores. «column_stack» construye dos columnas. Matplotlib separa la figura completa de los ejes que contienen curvas y etiquetas [R04]. Guarda este código como «primera_grafica.py» y ejecútalo con el intérprete del entorno.

Path une carpetas y nombres con el separador apropiado del sistema [R10]. Una ruta relativa parte del directorio de trabajo, que puede diferir de la carpeta del archivo. Imprime «Path.cwd()» si no encuentras el resultado. En Windows, una ruta literal con barras invertidas puede usar «r"C:\datos\ensayo.csv"» para evitar escapes inesperados.

$$
x(2)=8e^{-0.5\cdot2}\approx2.943
$$

Si obtienes alrededor de 5,89, revisa si cambiaste x0. Si obtienes una recta, revisa si usaste exponencial o una aproximación lineal. Aprender a programar consiste en relacionar una instrucción con una consecuencia comprobable, antes de añadir complejidad.
